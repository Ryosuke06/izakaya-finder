## 2. 現在の課題

1. トレーシングが未実装
- `traceId`, `traceUrl` を state に持てるが、Langfuse 連携は未着手

2. `tsc` の別件エラー
- `sample.ts(80)` の `implicit any` が残っている
- 本件のGraph実装とは直接無関係だが、全体ビルドでは失敗する

3. 返却 JSON の品質確認
- API Route からレスポンスが返る状態になったため、`candidates`, `ranked`, `reasons`, `summary` の内容確認が必要
- 現状の候補収集は LLM 生成のため、店名・住所・Google Maps URL の実在性確認が必要

## 3. 直近でやること（再開手順）

1. `docx/app-spec-draft.md` を先に確認（必須）
2. API Route から Graph を1回実行して疎通確認する
3. 返却 JSON の内容を確認する
- `candidates` が 5〜10 件程度返っているか
- `ranked` が `score` 順に並んでいるか
- `reasons` が入力条件に合った説明になっているか
- `summary` が自然な日本語で、入力条件に触れているか
4. Langfuse 連携方針を決める
- API Route 全体を親 trace にする
- 必要なら各 Node を子 span にする
5. 候補の実在性改善方針を決める
- `fetchCandidates` を Google Places API などの実データ取得へ寄せるか検討する
6. `sample.ts` の型エラーは必要時に別対応する
